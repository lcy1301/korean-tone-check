# Korean Tone Check

한국어 제품 문구와 UI를 일관된 문체로 작성·교정하기 위한 AI 지침형 스킬입니다. 문맥에 맞는 용어를 선택하고, 사용자에게 필요 없는 화면 설명을 정리합니다.

특정 모델의 말투를 판별하는 분류기나 독립 실행 프로그램은 아닙니다. Claude Code 등 스킬을 지원하는 도구에서 지침으로 사용하거나, AI 채팅에 첨부해 사용할 수 있습니다.

## 교정 기준

- 제품 설명에서 `새 판 → 새 버전`, `고치다 → 수정하다`, `훑다 → 검토하다`.
- 파일의 `받다 → 다운로드하다`, 화면 항목의 `고르다 → 선택하다`, 설정값의 `넣다 → 입력하다`.
- 불필요한 경어와 기술 동작의 의인화·비유 정리.
- 개발 메모와 중복 설명을 사용자 화면에서 제거.
- 상태는 짧은 배지, 행동은 버튼 문구, 조건은 라벨·값이나 요약문으로 표현.
- 아이콘의 뜻이 불명확하면 텍스트를 병기하고, 아이콘 버튼에는 접근성 이름 제공.

이 규칙은 개인적인 제품 문체 선호를 정리한 것입니다. 모든 한국어 글에 적용하는 정답이나 순우리말 금지 목록이 아닙니다.

## Claude Code 설치

이 저장소의 `skills/korean-tone-check` 폴더를 프로젝트의 `.claude/skills/` 안에 복사합니다.

```text
프로젝트/
└─ .claude/
   └─ skills/
      └─ korean-tone-check/
         └─ SKILL.md
```

Claude Code에 저장소를 전달하고 다음처럼 설치를 요청해도 됩니다.

```text
이 저장소의 skills/korean-tone-check 폴더를 현재 프로젝트의
.claude/skills/korean-tone-check에 설치해 줘.
같은 이름의 스킬이 있으면 덮어쓰기 전에 차이를 알려 줘.
설치 후 /korean-tone-check로 호출할 수 있는지 확인해 줘.
```

호출 예시:

```text
/korean-tone-check 이 프로젝트의 사용자 화면 문구를 검사하고 수정해 줘.
기존 기능과 디자인을 유지하고, 변경 내역과 확인 필요 항목을 알려 줘.
```

항상 작성 지침으로 적용하려면 [docs/CLAUDE.md](docs/CLAUDE.md)의 내용을 프로젝트의 기존 `CLAUDE.md`에 추가합니다. 기존 지침을 통째로 덮어쓰지 마세요. 스킬과 상시 지침은 필요한 방식으로 선택해 사용합니다.

설치와 호출 방식은 [Claude Code 공식 스킬 문서](https://code.claude.com/docs/en/skills), 상시 지침은 [공식 CLAUDE.md 문서](https://code.claude.com/docs/en/memory)를 참고하세요.

## 일반 AI 채팅에서 테스트

[SKILL.md](skills/korean-tone-check/SKILL.md)를 첨부하거나 내용을 붙여 넣고 다음 프롬프트를 보냅니다. 파일 첨부는 해당 대화에서 지침을 전달하는 방법이며, 스킬 설치와는 구분됩니다.

```text
첨부한 SKILL.md를 교정 기준으로 적용해 줘.
아래 글의 교정문, 위치별 변경 내역, 확인 필요 항목을 출력해 줘.
문맥상 뜻이 같은 경우에만 수정하고 주체·대상·조건·부정·수치를 보존해.
판단이 불확실하면 원문을 유지해. 규칙을 임의로 추가하지 마.

검사할 글:
[원문]
```

UI 검토는 화면 캡처나 코드를 함께 제공하고, 삭제·요약·배지·아이콘 전환의 이유를 요청하세요.

## 검증 상태와 한계

스킬 파일의 형식은 검증했습니다. 여러 모델에서의 교정 정확도나 UI 품질은 아직 체계적으로 평가하지 않았습니다. 예시는 검토 기준이며 자동 테스트 통과 기록이 아닙니다.

모델은 규칙을 놓치거나 과하게 적용할 수 있으므로 교정문과 변경 내역을 함께 확인하세요. 의미가 불확실하면 원문을 유지하고 `확인 필요`로 표시하도록 지시합니다.

## 개선 제안

Issue나 Pull Request에 원문, 원하는 수정안, 적용 맥락, 유지해야 할 반례를 함께 적어 주세요. 개인 정보나 공개 권한이 없는 원문 대신 익명화하거나 가상 예시를 사용해 주세요. 새 규칙은 문맥 보존 여부를 검토한 뒤 반영합니다.
