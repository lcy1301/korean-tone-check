# 문맥과 UI 교정 검토 사례

아래 사례는 스킬의 기대 동작을 확인하기 위한 가상 예시입니다. 특정 표현의 포함 여부만 확인하지 말고 의미 보존과 불필요한 수정 여부를 함께 검토하세요.

## 교정할 문장

| 원문 | 기대 수정안 | 확인할 점 |
| --- | --- | --- |
| 우리가 새 판에 태그 뽑기를 얹었습니다 | 새 버전에 태그 생성 기능을 추가했습니다 | 추가된 기능 보존 |
| 파일을 다시 받으세요 | 파일을 다시 다운로드하세요 | 재시도 의미 보존 |
| 시드에 숫자를 넣으세요 | 시드에 숫자를 입력하세요 | 입력 대상 보존 |
| 태그를 고치거나 지우세요 | 태그를 수정하거나 삭제하세요 | 두 동작 모두 보존 |
| 문서를 빠르게 훑어 주세요 | 문서를 빠르게 검토해 주세요 | 빠르게 검토하는 조건 보존 |
| 품절 상품을 빼서 후보를 좁히세요 | 품절 상품을 후보에서 제외하세요 | 제외 대상 보존 |
| 결과를 보면서 강도를 조금씩 올려 보시길 권해 드립니다 | 결과를 보면서 강도를 조금씩 높여 보세요 | 관찰·점진적 조절 조건 보존 |

## 유지할 문장

- 연결 코드를 받으세요: 다운로드가 아닌 코드 수신.
- 반죽에 버터를 넣으세요: 실제 재료를 넣는 동작.
- 빵을 굽습니다: 실제 조리.
- 화분에 씨앗을 심으세요: 실제 식물.
- 개정판의 판 번호를 확인하세요: 책의 판.
- 검색 범위를 좁히세요: 제외할 대상이 명확하지 않음.
- “우리가 이만큼 읽었네요”라고 말했다: 직접 인용.

## UI 형식 개선

| 원문과 맥락 | 기대 처리 |
| --- | --- |
| 카드 설명: 이 영역은 사용자의 편의를 위해 카드 형태로 구성했습니다 | 삭제: 디자인 의도는 사용자 행동에 필요하지 않음 |
| 상태: 현재 PC가 정상적으로 연결되어 있는 상태입니다 | `연결됨` 배지 또는 짧은 텍스트 |
| 버튼: 여기를 눌러 파일을 다운로드할 수 있습니다 | `다운로드` 버튼. 아이콘만 쓰면 접근성 이름 제공 |
| 요금제 카드: 현재 요금제에서는 로라를 1개까지 사용할 수 있습니다 | 현재 요금제가 보이는 맥락에서 `로라 최대 1개` |
| 오류: PC에 연결할 수 없습니다. 커넥터를 실행한 뒤 다시 연결하세요 | 문제와 복구 행동을 유지. 상태 배지만으로 대체하지 않음 |
| 조건: 월 1,500장, 매월 결제일 초기화, 이월 불가 | 세 조건 모두 유지. 목록 또는 라벨·값으로 정리 가능 |

## 검토 방법

원문을 스킬에 제공하고 교정문·변경 내역·확인 필요 항목을 요청합니다. 교정할 문장은 의미를 보존했는지, 유지할 문장은 불필요하게 바꾸지 않았는지 확인합니다. UI의 경우 필수 정보 보존, 중복 제거, 아이콘의 의미와 접근성을 확인합니다.
